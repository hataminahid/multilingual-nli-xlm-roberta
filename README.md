# Data

Download the competition data from Kaggle:
<https://www.kaggle.com/competitions/contradictory-my-dear-watson/data>

and place these files here:

```
data/
├── train.csv              (12,120 rows)
├── test.csv               (5,195 rows)
└── sample_submission.csv
```

The CSV files are git-ignored (Kaggle competition data should not be redistributed).
On Google Colab the setup cell asks you to upload the Kaggle zip instead.
